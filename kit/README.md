# Adverserial Confidential Kit

The installable `ack` CLI now has its own public repository:

<https://github.com/AdverserialAI/adverserial-confidential-kit>

Install the current public source with:

```sh
npm install -g github:AdverserialAI/adverserial-confidential-kit
ack init
ack code
```

The SDK repository remains the source for lower-level confidential inference
components and harness integrations.
